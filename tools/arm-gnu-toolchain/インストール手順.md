# 1.ダウンロード

以下から適切なバージョンをダウンロード  
URL：https://gitlab.arm.com/tooling/gnu-toolchains-for-arm/-/tree/releases/15.3.rel1?ref_type=heads  
ファイル名：arm-gnu-toolchain-15.3.rel1-mingw-w64-x86_64-arm-none-eabi.msi

# 2.インストール

arm-gnu-toolchain-15.3.rel1-mingw-w64-x86_64-arm-none-eabi.msiを実行。  
特に設定を変えずにNextをクリックする。

# 3.環境パスの設定

以下をシステム環境変数のPathに追加する。  
C:\Program Files\Arm\GNU Toolchain mingw-w64-x86_64-arm-none-eabi\bin

# 4.確認

PowerShell上で以下を実行し動作すること確認。

```text
arm-none-eabi-gcc -v
```
