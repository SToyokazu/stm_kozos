# 1.ダウンロード

Make for Windows を使用して、Windows の PowerShell / コマンドプロンプトから `make` を実行できる環境を用意する。

URL：https://gnuwin32.sourceforge.net/packages/make.htm

上記ページから以下をダウンロードする。

```text
Complete package, except sources
Setup
```

ダウンロードされるファイル名は以下。

```text
make-3.81.exe
```

ダウンロードしたインストーラは以下に保存する。

```text
tool\make-for-windows\make-3.81.exe
```

ファイル確認値は以下。

```text
Size: 3384653 bytes
MD5 : 8AE51379D1F3EEF8360DF4E674F17D6D
```

# 2.インストール

`make-3.81.exe` を実行する。

特に理由がなければ、インストール先はデフォルトのままにする。

代表的なインストール先は以下。

```text
C:\Program Files (x86)\GnuWin32
```

または以下。

```text
C:\Program Files\GnuWin32
```

Setup 版には実行に必要な GnuWin32 側の依存 DLL が含まれているため、Zip 版ではなく Setup 版を使用する。

# 3.環境パスの設定

PowerShell / コマンドプロンプトから `make` を使用するため、インストール先の `bin` ディレクトリをユーザー環境変数の `Path` に追加する。

Setup 版では `Path` が自動追加されない場合があるため、インストール後に確認して手動で追加する。

インストール先が `C:\Program Files (x86)\GnuWin32` の場合は以下。

```text
C:\Program Files (x86)\GnuWin32\bin
```

インストール先が `C:\Program Files\GnuWin32` の場合は以下。

```text
C:\Program Files\GnuWin32\bin
```

設定後、開いている PowerShell / コマンドプロンプトを閉じてから再度開く。

# 4.確認

PowerShell 上で以下を実行し、Make が起動することを確認する。

```text
make --version
```

以下のように GNU Make 3.81 のバージョン情報が表示されればインストールできている。

```text
GNU Make 3.81
```

Makefile があるディレクトリでは、以下でビルドを実行する。

```text
make
```

# 5.注意事項

Make for Windows は GnuWin32 の古い Win32 移植版である。

通常の Makefile 実行には使用できるが、Unix 系シェル前提の Makefile では `sh` や Unix コマンドが見つからず失敗する場合がある。

このプロジェクトでは Windows の PowerShell / コマンドプロンプトから `make` を呼び出す用途を前提にする。
