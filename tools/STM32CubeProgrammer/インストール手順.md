# 1.ダウンロード

以下からWindows 64-bit版をダウンロードする。  
URL：https://www.st.com/en/development-tools/stm32cubeprog.html  
ファイル名：SetupSTM32CubeProgrammer_win64.zip

STのダウンロードページでは、Cookieを有効にした上で、MySTアカウントでログインするかゲスト情報を入力する。  
ゲストの場合は入力したメールアドレス宛にダウンロード用リンクが送信されるため、メール内のリンク先からZIPファイルをダウンロードする。

# 2.展開

ダウンロードしたZIPファイルを任意のフォルダに展開する。  
展開後、以下のインストーラを確認する。

```text
SetupSTM32CubeProgrammer_win64\SetupSTM32CubeProgrammer_win64.exe
```

# 3.インストール

`SetupSTM32CubeProgrammer_win64.exe`を実行する。  
特に設定を変えずにNextをクリックする。

ST-LINKドライバのインストールを求められた場合はインストールする。  
Nucleo-F401REへの書き込みでは、オンボードST-Link/V2-1を使用する。

# 4.環境パスの設定

CLIから使用する場合は、以下をシステム環境変数のPathに追加する。

```text
C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin
```

# 5.確認

PowerShell上で以下を実行し、STM32CubeProgrammer CLIが起動することを確認する。  
バージョン情報が表示されればインストールできている。

```text
STM32_Programmer_CLI --version
```

Nucleo-F401REをUSB接続した状態で、ST-LINKが認識されることを確認する。

```text
STM32_Programmer_CLI -l
```

ST-LINKが認識されている場合は、`Connected ST-LINK Probes List`にボード情報が表示される。  
ST-LINKが認識されていない場合は、`No ST-Link detected!`と表示される。

認識されない場合は以下を確認する。

- Nucleo-F401REのUSBをST-LINK側のUSBコネクタに接続していること
- 充電専用ではなくデータ通信対応のUSBケーブルを使用していること
- USBを抜き差ししてから再度`STM32_Programmer_CLI -l`を実行すること
- デバイスマネージャーで`STMicroelectronics STLink`が表示されること

# 6.書き込み例

ビルド済みのバイナリをフラッシュROM先頭へ書き込む場合の例。

```text
STM32_Programmer_CLI -c port=SWD -w firmware.bin 0x08000000 -v -rst
```

`firmware.bin`は実際に生成したバイナリファイル名に置き換える。
